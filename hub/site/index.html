Small rooms for big interests.

SubX is a home for small, single-topic rooms. Pick a topic, read for free, and join when you want to talk.

  • One topic per room, so the talk stays on point.
  • Every post carries a WHOMARK™ label: Human-made, AI-made, or Human + AI.
  • Posted rules in every room, and a real report button.
  • Read without an account. Sign up only when you want to post.
